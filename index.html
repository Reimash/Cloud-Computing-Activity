What is Cloud Computing?

Cloud computing is the delivery of computing services, such as storage, servers, databases, networking, and software, over the internet instead of using local computers or physical hardware. It allows people and businesses to access resources on demand, pay only for what they use, and avoid the cost of maintaining their own physical infrastructure.

Cloud Computing Services

Google Drive

Google Drive is a cloud storage service that allows users to store files online and access them from any device with an internet connection. It also allows easy file sharing and collaboration.

Amazon Web Services (AWS)

AWS is a cloud computing platform that provides services such as computing power, storage, and databases to businesses and developers. It is widely used to host websites, applications, and large-scale systems.

GitHub

GitHub is a cloud-based platform used to store and manage source code. It allows developers to save their code online, track changes, and collaborate with other developers from anywhere.

Things I Learned About Cloud Computing

  • Cloud computing allows access to resources over the internet
  • Data can be stored remotely instead of on a local computer
  • Cloud platforms allow collaboration between multiple users
  • Cloud services can be scaled up or down depending on demand
